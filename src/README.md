# 扩散模型入门：从加噪到生成

这套教程面向已经了解神经网络、梯度下降和基本 Transformer，但第一次接触扩散模型（Diffusion Models）的读者。

读完这套教程，你将能够清晰地回答三个核心问题：
1. **模型学到了什么？**（为什么通过“加噪再预测噪声”就能学会生成新样本？）
2. **生成是如何进行的？**（如何从一团纯随机噪声一步步得到有结构的图像？）
3. **后续方法各自改进了什么？**（DDPM、DDIM、Latent Diffusion、CFG、ControlNet、DiT、Flow Matching 分别处于什么位置，解决什么问题？）

## 阅读建议

建议第一遍先顺着正文读完第 01 到 06 篇，抓住算法的核心思想和演进脉络；正文中的每个数学符号都会在附近用直白的话解释。如果遇到理解起来吃力的数学细节，可以先跳过第 07 篇（数学选读），不会影响理解主线。

每篇末尾都附有自测题和代表性论文入口。初次接触原论文时，建议先看 DDPM、DDIM、Latent Diffusion、CFG 和 DiT 的**摘要、方法示意图和算法流程框**，将详细推导留到第二遍阅读。更完整的文献脉络可参考上级目录的[学习地图](../README.md)与[本地论文 PDF 索引](../papers.md)。

## 方法演进与关系图

下面的概念图按“要解决的问题”梳理了主流方法之间的联系：

```text
2015 扩散概率模型：人为逐步加噪破坏数据，再训练模型学习反向生成过程
  └─ 2020 DDPM：引入易训练的高斯扩散与“噪声预测”目标，确立现代扩散模型基石
       ├─ 解决“采样步数太多、生成慢”
       │    ├─ 不重训模型，改变采样过程：DDIM / DPM-Solver（高阶 ODE 求解器）
       │    └─ 额外训练少步模型：Progressive Distillation（渐进蒸馏）/ Consistency Models（一致性模型）
       │
       ├─ 解决“高分辨率图像计算太贵”与“可控生成”
       │    └─ Latent Diffusion (LDM)：先用自编码器压缩图像，在潜空间（latent）做扩散
       │         ├─ 条件增强与空间控制：CFG（无分类器引导）/ ControlNet（附加空间控制分支）
       │         ├─ 个性化概念定制：Textual Inversion / DreamBooth
       │         └─ 骨干网络扩展：DiT（用 Transformer 替代 U-Net 作为去噪网络）
       │
       └─ 解决“连续时间统一建模与简化生成轨迹”
            └─ Score SDE（连续时间随机/常微分方程视角）
                 └─ Flow Matching / Rectified Flow（直接学习连接噪声与数据的速度场，如 Stable Diffusion 3）
```

> **提示**：这张图展示的是问题与思路上的演进关系，而非严格的论文引用树。图中不同分支往往对应不同的设计维度（例如表示空间、网络结构、训练目标、采样器），只要接口与数学设定兼容，它们在实际系统中经常组合使用。
