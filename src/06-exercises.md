## 实验一：亲眼观察前向加噪过程（零依赖 Python 实验）

- **实验目标**：直观体会“时间步 $t$ 的本质是噪声等级（由信号保留系数 $\bar{\alpha}_t$ 控制）”，看清训练样本 $x_t$ 是如何由干净数据 $x_0$ 和随机高斯噪声 $\epsilon$ 按公式直接合成的。
- **运行环境**：只需 Python 标准库（`math` 和 `random`），不需要安装任何第三方包，也不需要 GPU 或下载模型。

将以下代码保存为 `noise_demo.py`，在终端运行 `python noise_demo.py`：

```python
import math
import random

rng = random.Random(42)

# 用一个从 -1.0 到 1.0 均匀递增的 8 维向量代替“干净图片 x0”
x0 = [-1.0 + 2.0 * i / 7 for i in range(8)]

# 从标准高斯分布 N(0, 1) 采样一份随机噪声 epsilon
noise = [rng.gauss(0.0, 1.0) for _ in x0]

print("原始干净信号 x0 :", [round(x, 2) for x in x0])
print("随机高斯噪声 eps:", [round(x, 2) for x in noise])
print("-" * 68)

# 模拟不同时间步下的信号保留系数 alpha_bar（从接近 1 逐渐减小到接近 0）
for signal_retention in [0.99, 0.75, 0.25, 0.01]:
    xt = [
        math.sqrt(signal_retention) * x + math.sqrt(1 - signal_retention) * e
        for x, e in zip(x0, noise)
    ]
    print(f"alpha_bar={signal_retention:.2f} 时的带噪样本 xt: {[round(x, 2) for x in xt]}")
```

### 如何观察与理解输出结果？

1. **看整体趋势**：
   - 当 `alpha_bar=0.99`（对应很小的时间步 $t$）时，输出的 `xt` 与原始干净信号 `x0` 几乎一模一样；
   - 随着 `alpha_bar` 减小到 `0.75`、`0.25`，原有的递增规律逐渐被噪声打乱；
   - 当 `alpha_bar=0.01`（对应很大的时间步 $t$）时，原始信号几乎消失，输出的 `xt` 已经非常接近那份随机噪声 `eps`。
2. **两个值得留意的细节**：
   - 为了方便你直观对比同一个噪声向量在不同权重下的混合效果，上面的代码在四个噪声等级中**复用了同一份 `noise`**，用来展示单个时间步边缘分布 $q(x_t \mid x_0)$ 的加权性质。请注意，这**并不是**在模拟 DDPM 从 $t=1 \to 2 \to \dots \to T$ 的逐步马尔可夫加噪轨迹（真实的逐步加噪过程在每一步都会注入一份全新的独立高斯噪声）。
   - 如果你盯着向量里的某一个单独数字看，可能会发现它在 `alpha_bar` 减小时并不是严格单调变化的——这完全正常，因为公式保证的是整体分布的信噪比随 $t$ 规律变化，而在某一次具体随机采样中，某个位置的噪声值可能恰好与原信号方向相同或相近。

### 动手拓展建议
- 尝试把代码里的 `x0` 换成一个二维小灰度图案（比如 $8 \times 8$ 的字母或方框数组），并且每换一个 `alpha_bar` 都重新采样一份新的 `noise`，打印出来观察图案是如何一步步淹没在噪声里的。
- 如果你想进一步尝试自己写神经网络训练扩散模型，强烈建议先在**一维高斯混合分布、二维散点（如瑞士卷 / 双月数据集）或 MNIST 小图**上验证加噪与噪声预测闭环，千万不要一上来就直接从头训练高分辨率大图模型。

## 实验二：用“控制变量法”观察采样步数与 CFG 引导强度

如果你手头已经有现成的预训练文生图环境（例如基于 Diffusers 库或各类开源界面的模型），可以做一次标准的**控制变量实验**，亲身体会第 03、04 篇讲到的核心折中：

1. **固定基准条件**：固定同一个模型权重、同一句提示词（Prompt）、同一个随机种子（Seed）、同一分辨率、同一种采样器（如 DDIM 或 DPM-Solver）以及相同的硬件设备。
2. **第一组实验（只改变采样步数）**：保持 CFG 引导强度 $w$ 不变（例如设为默认值），只把采样步数依次设为 `10`、`20`、`50`，记录每次生成的耗时、网络调用次数（NFE）以及画面的细节变化。
3. **第二组实验（只改变 CFG 引导强度）**：把采样步数固定在效果较好的数值（例如 `25` 步），只把引导强度依次调小（如接近無引导）、适中、以及调得非常大（如 `15` 以上），观察画面与提示词的贴合程度、色彩饱和度以及是否出现伪影。

你可以参考下面的表格记录观察结果：

| 实验分组 | 采样步数 / NFE | CFG 引导强度 | 实际耗时 | 画面现象与质量观察 |
| :--- | :--- | :--- | :--- | :--- |
| **基准设置** | *例如 25 步* | *例如 7.0* | | *记录基准画面的结构与细节* |
| **只改采样步数** | *例如 10 步 / 50 步* | *保持 7.0 不变* | | *观察少步是否模糊、多步收益是否递减* |
| **只改 CFG 强度** | *保持 25 步不变* | *例如 1.5 / 15.0* | | *观察弱引导是否偏题、强引导是否过饱和失真* |

> **实验提示**：不同模型架构（例如普通 SD 1.5、SD3 或蒸馏加速模型）所适配的最佳步数和 CFG 强度范围差异很大。此外，单张图片受随机种子影响较大，不要仅凭单张图的偶然好坏给采样器下定论，建议多换几个提示词和随机种子综合观察。

## 综合自测：不看答案，检验六大核心概念

合上前面的笔记，试着用自己的话回答下面六个问题。如果都能流畅答出，说明你已经真正掌握了扩散模型入门的精髓：

1. **监督信号来源**：为什么在训练时我们能拿到真实的噪声作为监督标签，而在生成新图片时却拿不到？
2. **前向与反向的分工**：前向加噪过程和反向生成过程，分别是由什么决定的？哪一部分需要训练？
3. **两类提速路线**：在模型权重完全相同的前提下，DDIM 为什么能比原始 DDPM 用更少的步数完成生成？它和渐进式蒸馏（Progressive Distillation）在提速思路上有什么本质区别？
4. **模块角色定位**：`Latent Diffusion (LDM)`、`DiT`、`CFG`、`DPM-Solver` 这四个常见名词，各自回答的是生成系统里的什么问题？
5. **预测目标的关系**：“预测噪声（$\epsilon$）”、“估计 Score（对数密度梯度）”和“预测速度场（Velocity）”在任何模型里都是完全一模一样的东西吗？
6. **CFG 参数含义**：在本教程的公式约定 $\epsilon_{\mathrm{cfg}} = \epsilon_{\mathrm{uncond}} + w(\epsilon_{\mathrm{cond}} - \epsilon_{\mathrm{uncond}})$ 下，$w=1$ 代表什么含义？把 $w$ 调得越大就一定越好吗？

---

### 参考答案与解析

1. **监督信号来源**：
   训练时，带噪图片 $x_t$ 是我们拿真实图片 $x_0$ 和**自己随机采样的高斯噪声 $\epsilon$** 合成出来的，因此加了什么噪声一清二楚；而在生成阶段，我们是从一团全新的随机噪声起步去合成新样本，根本不存在一张事先藏好的原图和对应的加噪记录，所以只能靠神经网络去预测。
2. **前向与反向的分工**：
   前向加噪过程是由人为预设的高斯加噪公式（和噪声日程）直接规定的，不需要训练；反向生成过程则是由训练好的神经网络提供去噪预测，再配合采样器（调度更新规则）一步步计算出来的，其中神经网络的参数需要通过训练学习。
3. **两类提速路线**：
   DDPM 的训练目标只依赖单步边缘分布 $q(x_t \mid x_0)$，DDIM 利用这一性质构造了共享相同边缘分布的非马尔可夫采样路径，从而可以直接在稀疏的时间步子序列上更新而无需重训权重。它与蒸馏的本质区别在于：DDIM 只改推理时的**采样路线**（不改权重），而蒸馏需要付出额外训练成本，重新训练一个**学生模型**来学会一步跨多步（改变了权重）。
4. **模块角色定位**：
   - `LDM` 回答**表示空间**问题（在自编码器压缩后的潜空间里做扩散）；
   - `DiT` 回答**骨干网络结构**问题（用 Transformer 代替 U-Net 做预测网络）；
   - `CFG` 回答**条件引导增强**问题（在采样时组合有条件和无条件预测以强化条件作用）；
   - `DPM-Solver` 回答**数值采样方法**问题（用高阶 ODE 求解器减少采样步数）。
5. **预测目标的关系**：
   不是永远等同的。在标准高斯扩散设定下，理想的噪声预测与 Score（对数密度梯度）只差一个由噪声标准差决定的缩放系数，可以相互换算；而速度场（Velocity）的定义以及它与噪声、Score 之间的换算关系，则依赖于具体选择的概率路径（例如线性插值流还是高斯扩散路径）和参数化方式，不能脱离具体公式直接混用。
6. **CFG 参数含义**：
   在本教程的公式约定下，$w=1$ 刚好消去 $\epsilon_{\mathrm{uncond}}$，代表**普通的有条件预测**。$w$ 并不是越大越好：适度取 $w>1$ 能增强画面与文字条件的契合度，但过大的 $w$ 会牺牲生成多样性，并容易导致色彩过饱和或画面伪影。
